# Masks Solo / GM Oracles

Analog reference • Module version 0.3.0

By Doyce Testerman, with tables adapted from Shawn Tomkin’s *Ironsworn: Starforged* and *Sundered Isles*.

## Using the oracles

Choose a table, roll its listed die, and read the matching entry. Interpret the result through your current situation. For Action + Theme, roll independently on both tables and combine the results. Descriptor + Focus works the same way.

- **d100:** Roll percentile dice; 00 means 100.
- **Unusual dice:** For d24, roll a d6 and a d4: calculate (d6 − 1) × 4 + d4.
- **Roll twice:** Roll twice more on the same table and use both results. Reroll any further result that says “Roll twice.”
- **Action + Theme** or **Descriptor + Focus:** Roll once on each of those tables and combine the results.

## Ask the Oracle

For a yes/no question, choose the chance of “Yes” before rolling d100. A roll equal to or below that chance means Yes; a higher roll means No.

| Chance of Yes | Yes | No |
| --- | --- | --- |
| 10% | 1–10 | 11–100 |
| 25% | 1–25 | 26–100 |
| 50% | 1–50 | 51–100 |
| 75% | 1–75 | 76–100 |
| 90% | 1–90 | 91–100 |
